# 技術スタックの概要

## まとめ

- **フレームワーク・ライブラリは使っていません。** HTML・CSS・JavaScript だけで書いた 1 つのファイル(`index.html`)です。
- ビルドもインストールも不要です。ファイルをブラウザで開くだけで動きます。
- ホーム画面に追加して使うための追加ファイル(manifest・アイコン・Service Worker)が GitHub Pages 側にあります。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体。画面(HTML)、見た目(CSS)、ルール・思考・進行・描画(JavaScript)をすべて含みます |
| `manifest.webmanifest` | スマホのホーム画面に追加したときのアプリ名・アイコン・表示方法(全画面) |
| `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | アプリのアイコン(Android 用 / iPhone 用) |
| `sw.js` | Service Worker。ゲームのファイルを端末に保存し、通信がなくても遊べるようにします |
| `docs/AI.md` | コンピューターの思考アルゴリズムの説明 |

`index.html` は単体でも動きます。追加ファイルがない場所(ファイルを直接開いた場合や Claude のアーティファクト)では、manifest と Service Worker の部分は何もしません。

## 使っている技術

| 分野 | 内容 |
|---|---|
| 言語 | HTML、CSS、JavaScript(ES2015 以降。モジュールやトランスパイルはなし) |
| 盤の描画 | SVG。毎回、盤全体の SVG を文字列で組み立てて差し替えます。ボードを左右反転するときは全体を鏡写しにし、文字だけ元の向きに戻します |
| レイアウト | CSS Flexbox と Grid。スマホの横画面(高さ 520px 以下)では、盤を左、スコアとボタンを右に並べます |
| 盤の大きさ | `viewBox` を画面の縦横比に合わせて計算し、ポイント幅・駒・バーの大きさを変えます |
| 操作 | クリック/タップ(SVG の要素に `data-pt`・`data-act` を付けて判定)と、キーボード(Enter と Backspace) |
| ダイスの乱数 | `crypto.getRandomValues`(暗号用の乱数)。偏りが出ないように棄却法を使います |
| 設定の保存 | `localStorage`(ピップ数表示のオン/オフだけ) |
| コンピューターの思考 | 自己対戦で学習した小さなニューラルネットワーク(入力 212・中間 40・出力 5)を JavaScript だけで計算します。外部の機械学習ライブラリは使っていません |
| 上級の長い思考 | JavaScript の generator 関数で読みを少しずつ進め、`setTimeout` で合間に画面へ処理を返します(Web Worker は使っていません。単体ファイルのまま動かすため) |
| オフライン対応 | Service Worker。保存した版をすぐ表示し、裏で最新版を取りに行きます |

詳しいアルゴリズムは [AI.md](AI.md) にあります。

## 開発とテスト

開発中のテストは、Claude の作業環境で次の方法で行いました(テスト用スクリプトはリポジトリには含めていません)。

- **ルールと思考のテスト**: Node.js で、`index.html` のうち `// ==LOGIC START==` から `// ==LOGIC END==` までを取り出して実行します。
  - 合法手の生成(バー、ブロック、大きい目の優先、ベアオフ)を確かめます。
  - ギャモン・バックギャモン回避を確かめます。
  - レベル同士の対戦で勝率を測ります。
- **ニューラルネットワークの学習**: Node.js で自己対戦 30 万局を行い、学習した重みを `index.html` に埋め込みました。定石の応手表も、Node.js で上級より広く深く読んで作りました。
- **画面のテスト**: Playwright(ヘッドレス Chromium)で、PC・スマホ縦・スマホ横の画面サイズでマッチを最後まで自動で遊び、エラーがないこととスクリーンショットを確認します。
  - リファクタリングのときは、乱数と時計を固定して旧版と新版を同じ操作で動かし、盤の画像が 1 ピクセル単位で同じかを比べました。
- **ホーム画面・オフライン**: ローカルのサーバーで manifest が読めること、Service Worker が動くこと、通信を切っても再読み込みで遊べることを確かめました。
