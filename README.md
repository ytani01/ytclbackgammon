# ytclbackgammon

コンピューターと対戦するバックギャモン。`index.html` 1 ファイルだけで動きます。

**遊ぶ:** https://ytani01.github.io/ytclbackgammon/

- マッチ戦(1〜21 ポイント)、ダブリングキューブ、クロフォードルール
- コンピューターの強さ:初級・中級・上級(自己対戦で学習したニューラルネットワークで評価。上級は数手先まで読みます)
- ボードの向き(インナーボード右/左)、ピップカウント表示(盤の右端、切り替え可)
- キー操作:Enter = ダイスを振る/確定、Backspace = 戻す

上の URL(GitHub Pages)か、ダウンロードした `index.html` をブラウザで開いて遊べます。

## スマホのホーム画面に追加する

上の URL を開いてから、次のように追加するとアプリのように全画面で遊べます。一度開けば、通信がなくても遊べます。

- **iPhone(Safari)**: 共有ボタン(□に↑)→「ホーム画面に追加」
- **Android(Chrome)**: 右上の︙メニュー →「ホーム画面に追加」または「アプリをインストール」
